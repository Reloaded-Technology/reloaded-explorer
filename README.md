# Reloaded Explorer support site

Static documentation, privacy information and public issue tracking for Reloaded Explorer for Windows.

Site: https://reloaded-technology.github.io/reloaded-explorer/

This repository contains the website and its images only. It does not contain the desktop application's source, binaries, signing keys or Microsoft Store identity. The Microsoft Store release is still being prepared; no Store product ID has been assigned to this site.

The site uses GitHub Pages from the `main` branch, repository root. No package installation, custom build or analytics service is required.

The website originates from the app's `branding/site` directory. Existing demo screenshots were inspected before publication. The desktop app is based on Files, under the MIT License; its full third-party notices ship with its package. This website's applicable MIT license is included in `LICENSE`.
