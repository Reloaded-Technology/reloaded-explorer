Handy shortcuts

  • Ctrl + ` toggles the integrated terminal in the current folder. Ctrl + Shift + ` opens an external terminal.
  • Ctrl + T opens a new tab, and Ctrl + Shift + S opens a dual pane.
  • Ctrl + Alt + I toggles the info pane. Switch it to Preview to see Markdown, code, PDF, Excel and PowerPoint files.
  • Ctrl + Shift + P opens the command palette.

Troubleshooting

  • Drag and drop doesn't work while running as administrator. Windows blocks drag and drop between apps with different integrity levels. Run the app and the other app at the same level.
  • The terminal opens the wrong shell in a WSL folder. Make sure the distribution is running (wsl -l -v); the app opens the distro that owns the folder.
  • Logs: Settings → About → Open log location. You may attach a log to your report. Remove private file contents, usernames and credentials before posting to the public tracker.
