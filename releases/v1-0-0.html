Reloaded Explorer 1.0

Release preparation notes. Version 1.0 has not yet been published to the Microsoft Store.

  • Integrated terminal: press Ctrl + ` for PowerShell, CMD or WSL in the current folder, backed by a real Windows pseudo-console.
  • WSL-aware: Linux folders open in the matching distro's shell at the right path.
  • Native previews for PDF, Excel and PowerPoint, with no Office required.
  • Copy relative path, plus one-click new Markdown and HTML files.
  • Performance changes: spreadsheet previews and terminal allocations were optimized, with Git status, date labels and executable checks moved off the main window's synchronous work.
