Privacy Policy

Updated October 14, 2026 · Applies to Reloaded Explorer for Windows, maintained by Aldrin Gustavo Stori.

The short version

Reloaded Explorer is a file manager that runs on your PC. The planned Microsoft Store build does not enable the app's Sentry analytics or crash-upload integration and does not contain advertising. Local file operations and settings remain on your device. Optional network features and support requests are described below.

What stays on your device

  • App settings, pinned folders, file tags, tab layouts and terminal preferences are stored in the app's local data folder on your PC.
  • Logs used for troubleshooting are written locally. They are never uploaded automatically; you can open their location from Settings → About → Open log location and choose to share them with us.
  • Saved credentials for Git hosting or FTP servers use Windows-protected credential storage on your device.

When the app connects to the internet

Reloaded Explorer only makes network connections for features you use:

  • Microsoft Store distribution: payment, licensing and Store updates are subject to Microsoft's privacy statement. The Store version has not yet been published.
  • Release notes: after an update, the app may download a release notes page for the installed version from this website. The URL contains the version number. The hosting provider also processes ordinary connection information, such as your IP address.
  • Git features (clone, pull, push, sign in to GitHub) talk to the Git hosts you choose. Signing in to GitHub uses GitHub's device flow; the resulting token is stored locally and sent only to GitHub.
  • Network locations such as FTP servers, network shares, cloud-drive folders and WSL distributions are accessed only when you open them.
  • Integrated terminal commands run locally on your PC with your permissions; anything they send over the network is up to the commands you run.

Purchases

Microsoft Store distribution is being prepared. If you purchase a future Store release, Microsoft will process payment and licensing under its own terms. This website does not collect payment details or accept purchases. Microsoft may provide publisher reports under its Store policies.

This website and support

This static website is hosted by GitHub Pages. It does not load analytics scripts, advertising or third-party tracking resources. GitHub processes hosting requests under its privacy statement.

If you choose to report an issue on GitHub, your account name and the information you submit are visible on the public issue tracker. Support reports may contain personal data if you include it. Remove private file contents, usernames and credentials before sharing logs or screenshots. Reports are not uploaded automatically by the app.

Children

The app is a general-purpose productivity tool. It has no child-specific accounts or features.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

Questions about privacy: open an issue on our support page.
